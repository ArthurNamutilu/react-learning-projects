
# React Learning Projects

A collection of mini-projects built while learning React, JavaScript, and modern frontend development.

## Learning Goals

- Understand React components and JSX
- Practice props, state, and event handling
- Learn React hooks such as `useState` and `useEffect`
- Build reusable components
- Work with APIs and asynchronous data
- Practice responsive UI design
- Develop practical applications
- Improve problem-solving skills

## Projects

| Project | Concepts | Status |
|---|---|---|
| [Travel Journal](./travel-journal) | Components, props, JSX, responsive layouts | In progress |
| [Chef - Recipe Generator](./chef) | State, forms, events, recipe generation | Not started |

## Tech Stack

- React

## Running a Project Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/react-learning-projects.git
cd react-learning-projects
```

### Travel Journal

```bash
cd travel-journal
npm install
npm run dev
```

### Chef - Recipe Generator

From the repository root:

```bash
cd chef
npm install
npm run dev
```
